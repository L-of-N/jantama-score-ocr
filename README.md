# 雀魂スコアOCR

雀魂の終局リザルト画像をOCRで読み取り、Excelに戦績をまとめる非公式ツールです。

スクリーンショット画像からプレイヤー名、順位、素点、順位点を読み取り、全体サマリー、対戦相手別の同卓回数・勝率、プレイヤー別の個別戦績シート、読み取り確認が必要なデータ一覧を作成します。

> [!IMPORTANT]
> このツールは個人制作の非公式ツールです。雀魂の運営元とは関係ありません。
>
> OCR結果の正確性は保証できません。集計結果を利用する前に、必要に応じて元画像と照合してください。

## できること

- 雀魂のリザルト画像をまとめて読み取り
- 名前、順位、素点、順位点をOCR
- `master_result.xlsx` に読み取り結果を保存
- `summary_result.xlsx` に集計結果を出力
- 画像ハッシュで同じ画像の二重登録を防止
- 名前OCRの揺れを補正して保存
- 読み取りに不安がある箇所を「要確認」として出力

## 配布版の使い方

### 1. 必要なもの

配布先のPCにも [Tesseract-OCR](https://github.com/UB-Mannheim/tesseract/wiki) が必要です。

既定では、以下の場所にインストールされている前提です。

```text
C:\Program Files\Tesseract-OCR\tesseract.exe
```

Tesseract-OCRが入っていない場合、数字のOCRが動きません。

別の場所にインストールしている場合は、環境変数 `TESSERACT_CMD` に `tesseract.exe` のフルパスを設定してください。

例:

```text
C:\Tools\Tesseract-OCR\tesseract.exe
```

### 2. 配布フォルダを確認する

配布版を受け取った場合は、以下のフォルダごと使用してください。

```text
JantamaScore/
|-- JantamaScore.exe
|-- images/
|-- output/
|-- templates/
`-- _internal/
```

### 3. 画像を用意する

`images` フォルダに、雀魂の終局リザルト画面のスクリーンショットを入れてください。画像は複数枚まとめて処理できます。

対応形式:

- `.png`
- `.jpg`
- `.jpeg`

### 4. 実行する

1. `JantamaScore.exe` をダブルクリックする
2. 画像フォルダ、出力フォルダ、テンプレートフォルダを確認する
3. 「実行」を押す
4. 名前確認画面が表示されたら、必要に応じて名前を修正する
5. 個別シートを作成するプレイヤーを選ぶ
6. `output` フォルダに作成されたExcelファイルを確認する

## 出力ファイル

### `master_result.xlsx`

OCRで読み取った元データです。

主な列:

- 画像ファイル
- 順位
- 名前OCR
- 素点
- 順位点
- 確認フラグ
- 確認理由

### `summary_result.xlsx`

集計結果です。

主なシート:

| シート | 内容 |
| --- | --- |
| `summary` | プレイヤーごとの全体成績 |
| `vs_summary` | 対戦相手別の勝率集計 |
| `vs_raw` | 対戦相手別集計の元データ |
| `P_プレイヤー名` | 選択したプレイヤーの対戦相手別成績 |
| `戦績_プレイヤー名` | 選択したプレイヤーの個別戦績ページ |

### `name_alias.csv`

名前OCRの補正辞書です。一度修正した名前は、次回以降も補正されやすくなります。

## 確認フラグについて

確認フラグが「要確認」になっている行は、OCR結果を目視確認してください。

主な理由:

- 名前OCR失敗
- 素点OCR失敗
- 順位点OCR失敗
- 素点マイナス確認
- 名前手入力

特にマイナス点は誤読や確認漏れが起きやすいため、Excelで確認してください。

## 開発者向け

### Pythonで実行する

このフォルダで以下を実行します。

```powershell
python -m pip install -r requirements.txt
python main.py
```

または、`run.bat` を実行してください。

### exeを作り直す

`build_exe.bat` を実行すると、配布用フォルダが作成されます。

```text
dist/JantamaScore/
```

配布するときは、この `JantamaScore` フォルダごと渡してください。

## 注意点

- 初回起動時はEasyOCRのモデル読み込みで時間がかかることがあります。
- 画像が多いと処理に時間がかかります。
- 名前OCRは完全ではないため、確認画面で修正してください。
- 数字OCRも100%ではないため、「要確認」の行は必ず確認してください。
- 登録済みの画像は、画像ハッシュで判定されてスキップされます。
- 最初から読み直す場合は、`output/master_result.xlsx` を退避または削除してください。

## よくあるトラブル

### exeを起動しても何も表示されない

初回起動は少し時間がかかることがあります。しばらく待ってください。

それでも起動しない場合は、セキュリティソフトやWindowsの保護機能で止められている可能性があります。

### Tesseractが見つからない

Tesseract-OCRが以下にあるか確認してください。

```text
C:\Program Files\Tesseract-OCR\tesseract.exe
```

別の場所にある場合は、環境変数 `TESSERACT_CMD` を設定してください。

### 同じ画像が読み込まれない

一度読み込んだ画像は、重複防止のためスキップされます。

再読み込みする場合は、`output/master_result.xlsx` を退避または削除してから実行してください。

### 名前が文字化けする、または間違っている

名前確認画面で正しい名前に修正してください。

修正内容は `output/name_alias.csv` に保存され、次回以降の補正に使われます。

### Excelの列幅が見づらい

`summary_result.xlsx` は見やすい列幅になるように自動整形しています。

それでも見切れる場合は、Excel側で列幅を調整してください。
