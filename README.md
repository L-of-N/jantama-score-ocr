# 雀魂スコアOCR

雀魂のリザルト画像をOCRで読み取り、Excelに戦績をまとめるツールです。

スクリーンショット画像から、プレイヤー名・順位・素点・順位点を読み取り、以下のような集計ファイルを作成します。

全体サマリー
対戦相手別の同卓回数・勝率
プレイヤー別の個別戦績シート
読み取り確認が必要なデータ一覧
このツールは非公式です。雀魂の運営元とは関係ありません。

できること
雀魂のリザルト画像をまとめて読み取り
名前、順位、素点、順位点をOCR
master_result.xlsx に読み取り結果を保存
summary_result.xlsx に集計結果を出力
同じ画像を二重登録しないように画像ハッシュで判定
名前OCRの揺れを補正して保存
読み取りに不安がある箇所を「要確認」として出力
配布版の使い方
配布版を受け取った場合は、以下のフォルダごと使ってください。

JantamaScore/
  JantamaScore.exe
  images/
  output/
  templates/
  _internal/
JantamaScore.exe をダブルクリックすると、フォルダ選択画面が開きます。

images フォルダに雀魂のリザルト画像を入れる
JantamaScore.exe を起動する
画像フォルダ、出力フォルダ、テンプレートフォルダを確認する
「実行」を押す
名前確認画面が出たら、必要に応じて名前を修正する
個別シートを作るプレイヤーを選ぶ
output フォルダにExcelファイルが作成される
必要なもの
配布先PCにも Tesseract-OCR が必要です。

既定では、以下の場所にインストールされている前提です。

C:\Program Files\Tesseract-OCR\tesseract.exe
Tesseract-OCR が入っていない場合、数字のOCRが動きません。

Tesseract-OCR の場所を変えたい場合
Tesseract-OCR を別の場所に入れている場合は、環境変数 TESSERACT_CMD に tesseract.exe のフルパスを設定してください。

例:

C:\Tools\Tesseract-OCR\tesseract.exe
入れる画像
images フォルダに、雀魂の終局リザルト画面のスクリーンショットを入れてください。

対応形式:

.png
.jpg
.jpeg
画像は複数枚まとめて入れられます。

出力ファイル
実行後、output フォルダに以下のファイルが作られます。

master_result.xlsx
OCRで読み取った元データです。

主な列:

画像ファイル
順位
名前OCR
素点
順位点
確認フラグ
確認理由
summary_result.xlsx
集計結果です。

主なシート:

summary: プレイヤーごとの全体成績
vs_summary: 対戦相手別の勝率集計
vs_raw: 対戦相手別集計の元データ
P_プレイヤー名: 選択したプレイヤーの対戦相手別成績
戦績_プレイヤー名: 選択したプレイヤーの個別戦績ページ
name_alias.csv
名前OCRの補正辞書です。

一度修正した名前は、次回以降も補正されやすくなります。

確認フラグについて
確認フラグ が 要確認 になっている行は、OCR結果を目視確認してください。

主な理由:

名前OCR失敗
素点OCR失敗
順位点OCR失敗
素点マイナス確認
名前手入力
特にマイナス点は誤読や確認漏れが起きやすいので、Excelで確認してください。

開発者向け: Pythonで実行する場合
Python環境で直接実行する場合は、このフォルダで以下を実行します。

python -m pip install -r requirements.txt
python main.py
または、run.bat を実行してください。

開発者向け: exeを作り直す場合
build_exe.bat を実行すると、配布用フォルダが作成されます。

dist/JantamaScore/
配布するときは、この JantamaScore フォルダごと渡してください。

注意点
初回起動時はEasyOCRのモデル読み込みで時間がかかることがあります。
画像が多いと処理に時間がかかります。
名前OCRは完全ではないため、確認画面で修正してください。
数字OCRも100%ではないため、要確認 の行は必ず見てください。
すでに登録済みの画像は、画像ハッシュで判定されてスキップされます。
もう一度最初から読み直したい場合は、output/master_result.xlsx を退避または削除してください。
よくあるトラブル
exeを起動しても何も出ない
初回起動は少し時間がかかることがあります。しばらく待ってください。

それでも起動しない場合は、セキュリティソフトやWindowsの保護機能で止められている可能性があります。

Tesseractが見つからない
Tesseract-OCR が以下にあるか確認してください。

C:\Program Files\Tesseract-OCR\tesseract.exe
別の場所にある場合は、環境変数 TESSERACT_CMD を設定してください。

同じ画像が読み込まれない
一度読み込んだ画像は、重複防止のためスキップされます。

再読み込みしたい場合は、output/master_result.xlsx を退避または削除してから実行してください。

名前が文字化けする、または間違っている
名前確認画面で正しい名前に修正してください。

修正内容は output/name_alias.csv に保存され、次回以降の補正に使われます。

Excelの列幅が見づらい
summary_result.xlsx は見やすい列幅になるように自動整形しています。

それでも見切れる場合は、Excel側で列幅を調整してください。必要であれば、その調整内容をコード側に反映できます。
